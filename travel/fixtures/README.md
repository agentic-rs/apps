# Example trips

Each JSON file is a complete Fieldnotes journal that can be loaded with `parseJournal`. Dates in 2030 and record timestamps are fixed test values. The numbered days and stop order come from the guides below. All three trips start in the planning state, with empty check-ins and no photos.

| Fixture                     | Scenario                                                                                                                                             | Route source                                                                                                                           |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| [Kyoto](kyoto.json)         | One morning, five walkable stops. Open the day map to follow the two lanes between the temple and breakfast.                                         | [Kyoto City Tourism Association · Higashiyama at Dawn](https://kyoto.travel/en/itineraries/higashiyama-at-dawn/)                       |
| [Singapore](singapore.json) | Three days in one city, four stops per day. Switch from Chinatown and Little India on day two to Sentosa and Mount Faber on day three.               | [Wikivoyage contributors · Three days in Singapore](https://en.wikivoyage.org/w/index.php?title=Three_days_in_Singapore&oldid=5123726) |
| [Kansai](kansai.json)       | Three days, nine stops. The overview shows Kyoto → Nara on day two and Nara → Osaka on day three. Both transfer days begin with the arrival station. | [Japan National Tourism Organization · The Kansai Trio](https://www.japan.travel/en/itineraries/the-kansai-trio-kyoto-nara-and-osaka/) |

From the repository root, run `bun test ./travel/tests/example-itineraries.test.ts` to validate the journals. Run `bun run --cwd travel test:native` to open each through the native bridge in disposable storage and capture the Kansai overview in `travel/artifacts/qa/kansai-overview.png`. The harness uses the Firefox setup described in the [Fieldnotes verification guide](../README.md#verification).

## Sources and adaptation

The Kyoto fixture separates Sannenzaka and Ninenzaka into individual stops. The Kansai fixture selects three stops per day from the longer route. Place names, relative order and rail connections follow the respective publishers. The fixture descriptions and notes were written for Fieldnotes.

The Singapore fixture takes selected stops from the guide’s three independently usable day routes and schedules them on consecutive dates. It is an abridged adaptation by the Fieldnotes project, distributed under the same license as the guide. [Wikivoyage contributors and revision history](https://en.wikivoyage.org/w/index.php?title=Three_days_in_Singapore&action=history) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

For the original 行程助手 reference, Airbnb and QYER published links to real plans for Tokyo, Bangkok, Los Angeles and other destinations. The collection is a reference for comparing the app’s shared-trip flow. [Airbnb and QYER itinerary collection](https://news.airbnb.com/zh/tips-from-kol-make-your-golden-week-incredible)
